# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

The dashboard is a local browser surface embedded in a macOS/Linux command-line binary.

## Stack

Go with embedded HTML, CSS, and JavaScript. No browser framework, asset CDN, or separate JavaScript runtime is required to use the product.

## Users

A person maintaining skills and MCP connections across coding agents, projects, and machines. The first user is the repository owner, who wants to stop repeatedly reconstructing how the setup works.

## Product Purpose

Record the intended setup, discover what is actually installed, and expose differences. Tool ownership must not hide content changes. Compare accepted files, installed files, and safely inspectable current tool output.

## Operating Context

Checks are explicitly invoked. No background schedule or terminal hooks. Unknown installations stay working and are reported for adoption or dismissal. Machine groups are calculated from user-defined conditions, including hostnames.

## Capabilities and Constraints

- A portable CLI and local dashboard for macOS and Linux.
- Skillshare handles its supported installation and agent-linking work.
- Tool-specific integrations inspect tool-owned skills.
- Read-only checks must report uncertainty rather than imply a successful comparison.
- MCP credentials must not appear in reports or enter the shared repository.
- Backups and explicit actions protect live agent configuration.
- The dashboard initially inspects reports; mutations are explicit CLI commands.

## Product Principles

- Make ownership and uncertainty visible.
- Preserve the user's existing setup until an explicit change.
- Show actual content differences, not only version labels.
- Prefer one understandable workflow over disconnected tools.
- Keep the binary self-contained at runtime.

## Accessibility & Inclusion

Plain language, low cognitive load, keyboard-operable controls, legible contrast, and responsive layouts. No color-only state communication.
